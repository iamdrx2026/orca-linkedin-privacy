ORCA Social Agent — Privacy Policy

Effective: 24 November 2026

ORCA Social Agent (internally called ORCA LinkedIn Agent) is a personal workflow project for preparing, reviewing and managing the account owner's professional LinkedIn content. It is not a LinkedIn product or an affiliated service.

Information and purposes

The current local version stores user-supplied draft text, revision identifiers, approval status and optional imported aggregate engagement metrics on the owner's device. If the owner later authorizes the official LinkedIn API, the intended integration will use only granted permissions for account identification and explicitly approved publication. No LinkedIn API connection is active in the current version. Patient-identifiable information, confidential workplace records and account passwords must not be entered.

Storage and sharing

The local workflow stores drafts in a local SQLite database. Its current implementation does not send data to external services. If an authorized API integration is enabled later, approved content and required authorization data will be transmitted to LinkedIn to perform the requested action. Separate AI or design services chosen by the owner have their own privacy terms. The project does not sell personal data or use it for advertising. This static policy page is hosted by GitHub Pages, which may process ordinary web request information under its own privacy statement.

Control and retention

The account owner controls which drafts are retained and may delete the local database and any exported files. If the API connection is enabled, the owner may revoke it through LinkedIn settings and remove locally retained authorization material. Published posts can be managed through LinkedIn; removing local copies does not remove published posts. The intended workflow requires explicit approval before publication.

Changes and contact

This policy will be updated before materially different data processing is introduced. Questions or requests may be submitted to the project maintainer through the project's GitHub issues page; please do not include private information in public issues.

See also the LinkedIn privacy policy and GitHub privacy statement.
